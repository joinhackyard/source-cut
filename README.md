# Source Cut

Make documentaries where every frame has a source.

Source Cut is the open-source workflow Hackyard uses to make its business documentaries: real archive footage, real
photographs and real documents on screen, with a marker that sweeps across the exact words the narrator is saying.
No stock footage, no AI-generated people presented as real, and a credit for every picture.

This repository is being built up commit by commit. The full guide lands in this README at the end.
