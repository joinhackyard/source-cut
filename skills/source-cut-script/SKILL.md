# Script

Read `playbooks/series-documentary.md` for the full format. The short version:

## Film (6–8 minutes, about 900–1,100 words)

1. **Cold open (4 lines, ~30 s):** the most surprising true fact first, on its document. Then the turn. End with a key
   line on black (the promise of the film), then the title card.
2. **Five chapters**, each with a two- or three-word title. Each chapter is a run of narration lines, quotes and cards.
3. **Re-hook** around 70% through: a new question that pulls the viewer to the end.
4. **The lesson:** three numbered takeaways, each a short key line on black, then a checklist card.
5. **Close:** return to the opening fact; then the end card.

## Short (about 50 s, 6–8 lines)

Frame one is the hook on a real document card. Three tiny chapters. The last line runs back into the first so the loop
is seamless (for example, "On paper, it was worth" → "$47 billion.").

## Line rules

- One or two sentences per line. A line is the unit the edit places, captions and marks.
- Write numbers the way they should be said: "forty-seven point two billion dollars", "nineteen ninety-seven".
- Use the source's own words for anything that will be marked on a card, so the marker sweeps exactly what is said.
- Attribute opinions: "CNBC reported that…", "In WeWork's announcement, Neumann said…".
- No hype words, no "insane", no "you won't believe". Plain, international English.
- Every line has a picture: a document card with the words to mark, a photo, a quote clip, a band of footage, or a key
  line on black. Plan it in `SCRIPT.md` next to the line.

## Output

`SCRIPT.md` (lines with pictures) and `voice/lines.tsv` (`id<TAB>text`). Ids: film `w0a`, `w0b`, … by chapter
(`w1a` is chapter 1), Short `v0a`, `v0b`, ….

Read it aloud (or voice it) before locking. A line that is hard to say is hard to hear.
